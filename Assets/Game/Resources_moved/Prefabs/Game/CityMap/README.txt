City Map 占位预制体
==================

比例尺：设计单位 1 = 50 米
路宽：12 m
地块内过道：6 m
规则：地块之间必须隔马路；地块内建筑用过道分隔；“空位”为无遮挡开放设施（绿）。

颜色
----
米色  LotPad     地块底板
深灰  Road       马路
黄色  Corridor   地块内过道
绿色  OpenFacility  停车场/小广场等开放设施
蓝色  Building 1x1
青色  Building 2x1
青绿  Building 1x2
紫色  Building 2x2

生成方式
--------
Unity 菜单：Game → City Map → Generate Placeholder Prefabs

输出目录
--------
Pieces/   基础零件
Layouts/  各地块布局组合
Demo/     四块 2x2 地块 + 十字马路示例
